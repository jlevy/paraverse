Problem: the PostToolUse hook runs `tbd closing` and prints its checklist as plain text on stdout. Codex's hook docs (learn.chatgpt.com/docs/hooks) say that for PostToolUse "Plain text on stdout is ignored"; only JSON with `hookSpecificOutput.additionalContext` reaches the model. Claude Code behaves the same way: its hook docs (code.claude.com/docs/en/hooks) list only UserPromptSubmit, UserPromptExpansion, SessionStart and PostModelSwitch as events whose plain stdout becomes context, so the Claude copy of this hook has the same defect.

Verified: piping `{"tool_input":{"command":"git push origin setup/tbd"}}` into the hook prints 38 lines of Markdown (`# Session Closing Protocol` ...) and exits 0, with no JSON wrapper.

Disposition: deferred. The script is generated by `tbd setup`, which overwrites local edits. Upstream fix: have the generated hook wrap the `tbd closing` text in `{"hookSpecificOutput":{"hookEventName":"PostToolUse","additionalContext":...}}` for both Claude Code and Codex. Related upstream issue: jlevy/tbd#179 (open question on advisory stdout versus additionalContext). Waits on a tbd release with the fix, then `tbd setup --auto` here.
